# Image de développement TIAGo

Placer dans ce dossier l'archive fournie par PAL Robotics :

```text
TIAGo-development-computer-ubuntu-20.04.tar.gz
```

`build.sh` importe cette archive sous le nom
`palrobotics/tiago-devel-pc` avant de construire l'image
`epan/tiago:noetic`.

L'archive locale fait plusieurs gigaoctets et ne doit pas être ajoutée à Git.
